# Turbo Town — Plan & Progress

How to use this file:
- `[x]` = done, `[ ]` = not started, `[~]` = in progress / partly done.
- Add new ideas under **Backlog** in the section that fits; move them up to a
  milestone when you decide to build them.
- When something ships, tick it and add a line to the **Log** at the bottom.

Tech: Godot 4.7.2 · Forward+ renderer (Vulkan) · Jolt physics at 120 Hz with
physics interpolation · all code in GDScript · vehicle models generated by
`tools/blender/make_car.py` and `tools/blender/make_traffic_vehicles.py`.

---

## v0.1 — Core prototype (done)

### Driving
- [x] Raycast suspension (springs, dampers, bump stops, anti-roll bars)
- [x] Slip-based tire model with friction circle; grip varies by surface
- [x] Engine torque curve, automatic 5-speed gearbox, reverse, engine braking
- [x] Speed-sensitive steering, handbrake slides, drag and downforce
- [x] Assists: traction control, stability control, mid-air leveling, auto-hold (T = drift mode)
- [x] Rollovers, jumps and landings; R flips the car upright
- [x] Cosmetic body lean / squat / dive, brake and reverse lights

### Camera & controls
- [x] Chase camera: smooth follow, speed FOV, wall collision, impact shake
- [x] Camera modes: chase / far / hood (C), look back (Q), mouse + right-stick orbit
- [x] Keyboard bindings + gamepad bindings (`scripts/core/input_setup.gd`)

### Presentation
- [x] Stylized sports car model with spoked wheels (Blender script)
- [x] HUD: speedometer, gear, RPM, damage %, controls help, air-time popups, flip hint, pause
- [x] Synthesized sound: engine, tire squeal, wind, impacts, horn
- [x] Effects: tire smoke, off-road dust, skid marks, impact sparks
- [x] Cosmetic crash dents (repaired on reset)

### World
- [x] Island terrain with sea, beach, rolling hills and a mountain
- [x] City: 16 blocks, window-shaded buildings, parks, plaza, parking lots, sidewalks with drivable curbs
- [x] Ring highway: 3 lanes each way, median + edge barriers, two overpasses on pillars
- [x] Mountain loop road + summit road with a big jump
- [x] Stunt park: kickers, gap jump, table-top, 14 m mega ramp, quarter/half pipes, bumps
- [x] Dirt fields with jumps, gas station, highway exit signs, billboards, trees, clouds
- [x] Knock-over props: cones, barrels, crates, bowling pins, lamp posts, parked cars
- [x] Teleports (1–6 / Tab), respawn (Backspace), auto-respawn after falling in the sea

### Dev tools
- [x] Physics autotests (`scenes/dev/physics_test.tscn`, `--autotest=...`)
- [x] Screenshot tour, autopilot drive, effects/crash capture (`--tour`, `--drive`, `--fx`)

## v0.2 — Traffic & polish

### AI traffic (done)
- [x] Lane graph built from the roads: turn curves, T-junctions, highway merges, U-turns at dead ends
- [x] AI driver: pure-pursuit steering, IDM car following, curve speeds, give-way rules
- [x] Demand-actuated traffic lights with working light props
- [x] Crash reactions (stunned → recover or give up), wrecks removed out of view
- [x] Spawner around the player (~22 cars), refills after teleports, G toggles traffic
- [x] Traffic sounds: engine hum, crash thumps, honking at a player who blocks them
- [x] Traffic tests: `--traffic`, `--rampage`, `--bench`, lane graph check
- [x] Fixed: terrain poking up through the highway ramps and mountain road

### Traffic vehicle variety (done)
- [x] New vehicles: sedan, van, delivery truck, city bus (+ steel wheel), each with its own physics
- [x] Weighted traffic mix with per-type paint palettes; parked sedans and vans in the lots
- [x] AI adapts to vehicle size: following gaps, sensors, steering-limited curve speeds, gentler acceleration for heavy vehicles
- [x] Trucks and buses avoid dead-end roads (they can't make the tight U-turns)
- [x] AI backs up and retries when wedged (up to 3 tries) instead of giving up
- [x] Physics tests run on any vehicle (`--vehicle=...`); `--showcase` and `--uturn` dev tests

## Known issues
- The map is generated at startup, so the editor viewport only shows sky and sun.
- Damage is cosmetic only.
- Traffic never changes lanes; highway traffic stays in the lane it spawned in, and
  the two directions of the highway loop never mix.
- Engine sounds were tuned by measured levels, not by ear.
- Gamepad bindings exist but haven't been tried on a real controller.
- Headless runs print a harmless "ObjectDB instance leaked" warning at exit.
- Buses and trucks swing a little into the oncoming lane on tight city corners (like real
  ones); rarely this jams with an oncoming car until one of them backs up.
